Free and open source for macOS

Speak. Whispur types it for you.

Whispur is a voice dictation app that lives in your Mac menu bar. Hold a shortcut, talk, and let go: your words are transcribed, tidied up and pasted into whatever app you are using.

Features

Built like a native Mac app

Whispur stays out of the way in your menu bar until you need it, then turns speech into text you would actually send.

  • Hold to talk, or toggle

    Hold Fn to dictate and release to paste. Press Command + Fn for hands-free recording, or pick Fn twice in Settings. Esc cancels.

  • Pastes where your cursor is

    Text lands in the app you are already using: email, Slack, your editor, a prompt box. Your clipboard is restored afterwards.

  • Five speech engines

    Apple speech recognition with no key needed, or OpenAI Whisper, Groq, Deepgram and ElevenLabs with your own API key.

  • Optional AI cleanup

    Run transcripts through Claude, OpenAI, Groq or AWS Bedrock to fix punctuation and misheard words. Edit the prompt and add your own vocabulary.

  • Bring your own keys

    No account, no subscription, no middleman. API keys live in the macOS Keychain and requests go straight to the provider you chose.

  • See every request

    The Activity tab shows raw and cleaned transcripts. The Requests tab lists every provider API call with its timing and any error.

  • Choose your microphone
  • Pick your dictation language
  • Quiet system audio while recording
  • Compact recording overlay
  • Learn corrections from your edits (opt-in)
  • Weekly dictation recap
  • Automatic updates

Install

Running in about a minute

  1. Download the DMG

    Get the latest Whispur.dmg from GitHub Releases. It is signed and notarized by Apple, so it opens normally.

  2. Drag it to Applications

    Launch Whispur. It runs from the menu bar, and Settings opens a setup checklist.

  3. Grant two permissions

    Allow Microphone to record and Accessibility for the global shortcut and paste. Then hold Fn and talk. The Apple engine also asks for Speech Recognition access on first use.

FAQ

Questions, answered

Is Whispur really free?

Yes. Whispur is MIT licensed, with no account and no subscription. Apple speech recognition works without an API key. If you choose a cloud provider, that provider bills you directly for your own usage.

Does Whispur see my audio or transcripts?

No. Whispur has no backend server. Audio and transcripts go only to the speech and cleanup providers you configure, using your own API keys, which are stored in the macOS Keychain.

Which speech-to-text engines does Whispur support?

Apple speech recognition built into macOS, OpenAI Whisper, Groq Whisper Large v3, Deepgram Nova-3 and ElevenLabs Scribe v2. The OpenAI provider also accepts a custom OpenAI-compatible base URL.

Which Macs are supported?

Macs running macOS 14 Sonoma or later. The current release build runs on Apple silicon.

What is the default shortcut, and can I change it?

Hold Fn to talk and release to paste. Press Command + Fn to start hands-free recording and press it again to stop. You can pick other shortcuts in Settings, including Fn twice (set "Press 🌐 key to" to Do Nothing in System Settings > Keyboard first), and Esc cancels a recording.

How does AI cleanup work?

Add an API key for Anthropic, OpenAI, Groq or AWS Bedrock and Whispur passes each transcript through that model before pasting, fixing punctuation, capitalization and misheard words. You can edit the cleanup prompt, add custom vocabulary and set a custom model. If cleanup fails, Whispur pastes the raw transcript instead.

How do updates work?

Whispur updates itself through Sparkle. Every release is signed with an Apple Developer ID certificate, notarized by Apple, and checked against an EdDSA signature before it installs.

Can I install Whispur with Homebrew?

Not yet. A Homebrew cask is planned but not published. For now, download the DMG or build from source.

Where is the source code?

On GitHub at github.com/sophiie-ai/whispur. Issues and pull requests are welcome.
